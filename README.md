# 🎵 Flex Music

**一个基于 Kotlin 开发的轻量级本地音乐播放器**

[![Release](https://img.shields.io/badge/release-v1.0-green.svg)](https://github.com/kingmuchen/Flex-Music/releases)
[![Platform](https://img.shields.io/badge/platform-Android%208.0%2B-blue.svg)]()
[![License](https://img.shields.io/badge/license-Apache%202.0-orange.svg)](LICENSE)

</div>

## 说明

所用技术栈：

- Kotlin
- Jetpack Compose
- Hilt（依赖注入）
- Room（本地数据库）
- Media3 / ExoPlayer（音频播放）
- DataStore（偏好设置持久化）
- Coil（图片加载）
- Coroutines（异步处理）

已支持的平台：

- Android 8.0（API 26）及以上

软件下载请查看 [GitHub Releases](https://github.com/kingmuchen/Flex-Music/releases)。

目前本项目的原始发布地址只有 GitHub，其他渠道均为第三方转载发布，与本项目无关！

## 功能特点

- 🎶 **纯本地播放** — 无需联网，扫描本地音乐即可播放
- 🎨 **极简 UI** — 基于 Jetpack Compose 构建，界面简洁流畅
- 📝 **歌词匹配** — 支持内嵌歌词提取与在线歌词智能匹配
- 🎚️ **歌词偏移调节** — 支持歌词时间偏移微调，精准同步
- 🎵 **音频节奏分析** — 基于音频指纹与 DTW 对齐的歌词同步
- 🖼️ **封面获取** — 自动获取在线专辑封面，支持本地封面缓存
- 🔔 **通知栏控制** — 支持系统通知栏播放控制
- ⏯️ **后台播放** — 基于 Media3 PlaybackService 实现后台持续播放
- 💾 **进度记忆** — 自动记忆播放进度，下次打开继续播放
- ⚡ **极低占用** — 轻量化设计，内存占用极低，适配主流安卓版本

## 项目结构

```
app/src/main/java/com/kingmc/flexmusic/
├── data/                    # 数据层
│   ├── local/               # 本地数据库（Room）
│   ├── model/               # 数据模型
│   ├── repository/          # 仓库层
│   └── scanner/             # 媒体扫描器
├── di/                      # 依赖注入模块（Hilt）
├── feature/                 # 功能模块
│   ├── home/                # 首页（歌曲列表）
│   ├── player/              # 播放器
│   │   └── lyrics/          # 歌词相关（解析、匹配、对齐）
│   └── settings/            # 设置页
├── player/                  # 播放控制（Media3）
└── ui/                      # 通用 UI 组件与主题
```

## 源码使用方法

1. 安装 [Android Studio](https://developer.android.com/studio)（推荐最新稳定版）
2. 克隆本仓库：
   ```bash
   git clone https://github.com/kingmuchen/Flex-Music.git
   ```
3. 使用 Android Studio 打开项目，等待 Gradle 同步完成
4. 连接 Android 设备或启动模拟器，点击运行即可
